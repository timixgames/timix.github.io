FAQ

Как установить программу?

Шаг 1: Установка Python
Скачайте и установите последнюю версию Python с официального сайта python.org. При установке обязательно поставьте галочку "Add Python to PATH".

Шаг 2: Установка библиотек
Откройте командную строку (Win + R → cmd) и выполните:
pip install psutil mss pillow pyperclip

Шаг 3: Скачайте NirCmd
Скачайте NirCmd с nirsoft.net и скопируйте nircmd.exe в папку с программой.

Шаг 4: Настройка бота
Перейдите к @BotFather, создайте бота и вставьте токен в строку BOT_TOKEN = 'YOUR_BOT_API'.

Шаг 5: Получите Telegram ID
Перейдите к @userinfobot и вставьте ID в строку MY_USER_ID = YOUR_USER_ID.

Шаг 6: Первый запуск
Запустите бота, выберите язык интерфейса (Русский или English) — готово!

Требуется ли активация?

Нет, программа полностью бесплатна и не требует активации. Все функции доступны сразу после установки.

Какие системные требования?

Windows 10/11, 2 ГБ ОЗУ, 100 МБ свободного места на диске.

Есть ли обновления?

Да, программа регулярно обновляется. Проверить наличие обновлений можно в разделе "Помощь" внутри программы.

Какие функции доступны в боте?

Управление громкостью и яркостью, скриншоты, проверка активности ПК, сетевые подключения, запуск программ, управление питанием (сон, блокировка, перезагрузка, выключение), отслеживание местоположения, поиск ПК по звуку и многое другое.
