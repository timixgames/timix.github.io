FAQ

Как установить программу?

Шаг 1: Установка Python
Скачайте и установите последнюю версию Python с официального сайта python.org. При установке обязательно поставьте галочку "Add Python to PATH".

Шаг 2: Установка необходимых библиотек
Откройте командную строку (Win + R → cmd) и выполните следующие команды по очереди:
pip install psutil
pip install mss
pip install pillow
pip install pyperclip
Или одной командой:
pip install psutil mss pillow pyperclip

Шаг 3: Скачивание NirCmd
Скачайте утилиту NirCmd с официального сайта nirsoft.net/utils/nircmd.html. Распакуйте архив и скопируйте файл nircmd.exe в папку с программой.

Шаг 4: Подготовка папки
Создайте папку для программы (рекомендуется на системном диске, например: C:\). Не рекомендуется размещать на Рабочем столе или в папке Загрузок.

Шаг 5: Настройка Telegram-бота и токена
1. Перейдите в бота @BotFather
2. Нажмите /newbot и следуйте инструкциям:
- Придумайте имя для бота (например: "Мой ПК")
- Придумайте username бота (должен заканчиваться на _bot или bot, например: my_pc_control_bot)
3. Бот отправит вам токен в формате: 1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
4. Откройте файл программы в текстовом редакторе (например, PyCharm или Notepad++)
5. Найдите строку: BOT_TOKEN = 'YOUR_BOT_API'
6. Замените 'YOUR_BOT_API' на полученный токен

Шаг 6: Получение вашего Telegram ID
1. Перейдите в бота @userinfobot
2. Бот покажет ваш ID (например: 5427175293)
3. В файле программы найдите строку: MY_USER_ID = YOUR_USER_ID
4. Замените YOUR_USER_ID на ваш полученный ID

Шаг 8: Первый запуск
1. Перейдите в вашего бота)
2. Выберите язык интерфейса (Русский или English)
3. Готово! Бот теперь управляет вашим компьютером.

Требуется ли активация?

Нет, программа полностью бесплатна и не требует активации. Все функции доступны сразу после установки.

Какие системные требования?

Windows 10/11, 2 ГБ ОЗУ, 100 МБ свободного места на диске. Работает на всех версиях Windows 10 и выше.

Есть ли обновления?

Да, программа регулярно обновляется. Вы можете проверить наличие обновлений в разделе "Помощь" внутри программы.

Какие функции доступны в боте?

Бот позволяет: управлять громкостью и яркостью экрана, делать скриншоты всех мониторов, проверять активность ПК, просматривать сетевые подключения, получать отчёты об использовании системы, запускать программы, копировать текст в буфер обмена, проверять интернет, управлять питанием (сон, выход, блокировка, перезагрузка, выключение), отслеживать местоположение ПК и находить компьютер по звуку.
